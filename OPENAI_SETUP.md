# 🤖 Интеграция OpenAI в AI Бот

## Возможности

Проект поддерживает **два режима работы бота**:

### 1. 📝 **Keyword Mode** (Режим ключевых слов)
- Работает без интернета
- Быстрые ответы
- Базовые функции на основе ключевых слов
- **Бесплатно**

### 2. 🤖 **OpenAI Mode** (GPT режим)
- Использует GPT-3.5-turbo или GPT-4
- Умные контекстные ответы
- Понимает сложные вопросы
- Сохраняет контекст разговора
- **Требует API ключ OpenAI**

## Установка и настройка

### Шаг 1: Получите API ключ OpenAI

1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в раздел [API Keys](https://platform.openai.com/api-keys)
3. Нажмите "Create new secret key"
4. Скопируйте ключ (он показывается только один раз!)

### Шаг 2: Пополните баланс

1. Перейдите в [Billing](https://platform.openai.com/account/billing)
2. Добавьте платёжный метод
3. Пополните баланс (минимум $5)

### Шаг 3: Настройте backend

1. Откройте файл `backend/.env`
2. Добавьте ваш API ключ:

```env
OPENAI_API_KEY=sk-your-actual-api-key-here
```

### Шаг 4: Перезапустите backend

```bash
cd backend
npm run dev
```

## Использование

### Переключение режимов

В чате с ботом есть кнопка в правом верхнем углу:
- **📝** - Keyword Mode (без OpenAI)
- **🤖** - OpenAI Mode (с GPT)

Просто кликните на кнопку для переключения режима!

### Хранение истории чата

- История чата сохраняется **отдельно для каждого пользователя**
- Хранится только **до закрытия вкладки/браузера** (sessionStorage)
- При **logout** все чаты с ботом автоматически очищаются
- Каждый пользователь видит только свою историю общения с ботом

## Стоимость

### GPT-3.5-turbo (рекомендуется)
- ~$0.002 за 1000 токенов
- Примерная стоимость: **$0.001-0.003 за сообщение**
- Быстрый и недорогой

### GPT-4
- ~$0.03 за 1000 токенов
- Примерная стоимость: **$0.01-0.05 за сообщение**
- Более умный, но дороже

## Настройка модели

В файле `backend/src/controllers/aiController.ts` можно изменить модель:

```typescript
const completion = await openai.chat.completions.create({
  model: 'gpt-3.5-turbo', // или 'gpt-4', 'gpt-4-turbo-preview'
  messages: messages,
  max_tokens: 500,        // Максимум токенов в ответе
  temperature: 0.7,       // Креативность (0-2)
});
```

## Troubleshooting

### ⚠️ Ошибка "You exceeded your current quota"
**Причина:** На балансе OpenAI недостаточно средств

**Решение:**
1. Пополните баланс на [platform.openai.com/account/billing](https://platform.openai.com/account/billing)
2. Или используйте **Keyword Mode** (бесплатно) - бот автоматически переключится
3. Система автоматически покажет сообщение с инструкцией

### Ошибка "API key not found"
- Проверьте, что OPENAI_API_KEY добавлен в `.env`
- Перезапустите backend сервер

### Ошибка "Insufficient funds"
- Пополните баланс на [platform.openai.com](https://platform.openai.com/account/billing)

### Бот не отвечает
- Проверьте консоль backend на ошибки
- Убедитесь что backend запущен на порту 3000
- Переключитесь на Keyword Mode для проверки

## Отключение OpenAI

Если вы не хотите использовать OpenAI:
1. Просто не добавляйте OPENAI_API_KEY в .env
2. Используйте только Keyword Mode (📝)
3. Всё будет работать на основе локальных ответов
